# 高斯泼溅三维建模手机 App 设计文档

## 1. 核心需求

- **摄像头采集**：支持连续视频帧采集，记录时间戳。
- **位姿估计**：通过 ARKit/ARCore 获取相机位姿；必要时结合视觉里程计。
- **高斯泼溅建模**：生成 3D 高斯点云，用于真实场景渲染。
- **实时预览**：在移动端实时或准实时显示重建结果。
- **数据导出**：支持导出为 PLY/GLB/自定义格式。

## 2. 技术选型建议

### 2.1 客户端

- **iOS**：Swift + ARKit + Metal
- **Android**：Kotlin + ARCore + Vulkan
- **跨平台**：
  - Flutter + Platform Channels 调用原生 ARKit/ARCore
  - Unity/Unreal（若需快速 3D 渲染）

### 2.2 算法与训练管线

- **位姿与稠密重建**：COLMAP/ARKit/ARCore + 自研融合
- **高斯泼溅训练**：
  - 移动端轻量化训练（设备限制较大）
  - 端云协同：上传关键帧 + 位姿，云端训练

### 2.3 渲染

- 高斯渲染（GPU）：Metal/Vulkan/Unity
- 预览模式：逐帧增量更新

## 3. 模块拆分

1. **采集模块**
   - 摄像头视频流
   - 位姿与深度
2. **数据管理模块**
   - 帧缓存与关键帧选择
   - 数据序列化/上传
3. **重建与训练模块**
   - 位姿优化
   - 高斯点云训练
4. **渲染模块**
   - 高斯渲染
   - 实时预览
5. **导出与分享模块**
   - PLY/GLB 导出

## 4. 推荐开发里程碑

- **M1：原型验证**
  - 摄像头采集 + 位姿
  - 云端离线训练 + 结果回传
- **M2：实时预览**
  - 简易高斯渲染
  - 增量更新
- **M3：端云协同**
  - 优化上传与训练策略
  - 提升性能与质量
- **M4：产品化**
  - UI/UX
  - 导出与分享

## 5. 关键挑战

- 移动端算力限制
- 大规模高斯点云存储
- 实时渲染性能
- 位姿精度与同步
